## A. Recommend now — additive / non-breaking, this cycle

Land before updating the example apps. None change a published contract; all 10
example apps keep compiling. Two are genuine bug fixes.

### 1. `restore-prevmembers-id-index-mismatch` — **BUG, trivial, high**
`restore()` builds `prevMembers = queries.map(q => …)` (positional, `world.ts:1209`)
but reads `prevMembers[q.id]` (`world.ts:1222`). `q.id` is a world-global
monotonic counter; disposed queries are spliced out of `queries`. After **any**
query dispose, `index !== q.id`, so the `onRemove` lookup returns the wrong set
or `undefined` and `onRemove` misfires on restore. Existing
`snapshot.test.ts:117-132` passes only because it never disposes a query first
(`q.id === 0 === index`).
- **Fix:** index by array position (`queries.forEach((q,i) => { const removed = prevMembers[i] ?? [] … })`), capturing `makeView(id)` before the store wipe so `onRemove` receives a populated view.
- **Test (RED):** create+dispose 3 throwaway queries (diverge id from index), register a live `Has(Position)` query with an `onRemove` spy, spawn+step, `restore()` a snapshot lacking that entity → assert `onRemove` fired. Fails today.
- Files: `world.ts`, `test/snapshot.test.ts`. App impact: silent bugfix, no migration.

### 2. `reactive-ctx-entities` — **BUG, trivial, high**
`runSystem` sets `entities: s.query ? s.query.entities : []` (`world.ts:553`),
ignoring `s.reactsTo`. A reactive system declared with only `reactsTo: Changed(X)`
(no explicit `query`) gets `ctx.entities = []` — contradicting SPEC §§ at
`SPEC.md:301/374` ("reactive systems see the query delta"). The compiled
`reactsTo` query's `.entities` getter already yields the tick-filtered delta.
- **Fix:** `entities: s.query ? s.query.entities : (s.reactsTo ? s.reactsTo.entities : [])`. Explicit `query` still wins (back-compat).
- **Test (RED):** reactsTo-only reactive system captures `ctx.entities.map(v=>v.id)`; `markChanged(e1)` in a tick system; step → assert `[e1]` (today `[]`).
- Files: `world.ts`, `test/scheduler.test.ts`, `SPEC.md`, `api.md`. App impact: reactsTo-only reactive systems drop the `ctx.world.query(Changed(X))`-in-body workaround; explicit-query authors unchanged.

### 3. `component-value-helper` — trivial, high
No value-type extractor exists; 21 `ReturnType<typeof X.create>` sites across 7
app files (tessera, fleet, harbor, lighthouse, restaurant example).
- **Add:** `export type ComponentValue<C> = C extends ComponentType<infer T, string> ? T : never` (`types.ts`, re-export `index.ts`).
- Purely additive type. Apps swap `ReturnType<typeof Ship.create>` → `ComponentValue<typeof Ship>`.

### 4. `describe-domecs-error` — small, high
Closed 7-variant `DomecsError` union (`errors.ts:22-29`) has no formatter.
- **Add:** `describeError(e: DomecsError): string` built on `match()` (total → compile-safe when a variant is added). App toasts/console (lighthouse, studio, fleet) + inspector UI stop hand-rolling `switch(err.kind)`.

### 5. `result-tap-helper` — trivial, med
`result.ts` has `mapR/mapErr/andThen/unwrapOr/all` but no side-effect combinator.
- **Add:** `tap(r, fn)` / `tapErr(r, fn)`. Enables `tapErr(world.use(p), e => console.warn(describeError(e)))`. Pairs with #4.

### 6. `definePlugin` — small, med
No authoring helper; all 5 plugins hand-write `Plugin<O>` + `return ok({…})`
boilerplate, and the function-factory form loses `options:O` / re-annotates
`world:World`.
- **Add:** `definePlugin<O = void>(spec)`: lets `install` return a bare `PluginHandle | void` **or** a `Result` (auto-wraps bare via `'ok' in r`), passes `name/version/depends/provides` through. Registry untouched.
- Kills the lighthouse-class footgun: a bare-handle return authored via `definePlugin` stays valid through the Result-contract migration.

### 7. `doc-plugin-install-result-shape` — small, high (docs)
`api.md:438` / `SPEC.md:582-589` still document the **old** bare
`install(world): PluginHandle | void`; real code returns
`Result<PluginHandle | void, DomecsError>` (`plugin.ts:20`). A dev copying the
snippet won't compile. Fix the doc blocks; show `definePlugin` as the primary
path.

### 8. `doc-plugin-peerdepends-version` — trivial, med (docs)
`api.md:488` references a nonexistent `peerDepends`; `plugin.ts:17` declares
`version?: string` that the docs omit. Drop the phantom field, document
`version?`. Same doc blocks as #7 — batch together.

### 9. `persist-save-envelope-meta` — small, med
`persist.save()` takes no options and writes the raw snapshot; `WorldSnapshot.meta`
exists (`snapshot.ts:13`) but is never populated.
- **Add:** `save(world, storage, slot, opts?: { meta? })` merging `{ savedAt, …meta }` into `snap.meta`. 3-arg callers unchanged. Prereq for labeled history entries (B-tier).

### 10. `sideeffects-readme-license-inspector-persist` — trivial, med (packaging)
`inspector`/`persist` `package.json` lack `sideEffects:false` (core/dom/input
have it) and advertise `README.md`+`LICENSE` in `files` that **don't exist** on
disk → npm warns, tarball ships neither. Add the key, copy LICENSE, write short
READMEs, update `PACKAGING.md §7` to list all five. Coordinate with B-tier
release-validation.

**Ordered plan:** 1 → 3 → 2 (all touch `world.ts`) → 5 → 4 → 6 → 7 → 8 → 9 → 10.

## C. Defer — needs a design decision or is v0.2+/architectural

- `capability-typing` — `CapabilityMap` augmentation so `world.capability(name)` is typed without triple-casts (roguelike still triple-casts). Typing-contract change; schedule after A-batch.
- `markchanged-batch` — `markChangedMany`; only Harbor/Fleet-scale benefit. Fold into a perf pass.
- `rng-helpers` — PARTIAL (`int/range/pick/roll/fork` ship); only `oneOf/weighted/shuffle` missing. Ergonomic, not correctness.
- `dispatch-alias` — pure sugar over `turn()`/`step()`; settle after `action()`.
- `post-tick-snapshot-hook` — only the install-time self-`onSnapshot` half is open (one consumer: studio). Pair the doc note with history-ring.
- `componenttype-redaction` — transient-by-identity exclusion already exists; bundle the general exclude-set into one `SnapshotOptions` pass.
- `canonical-snapshot-hash` — real ordering risk, but serves determinism/replay test infra; defer to the v0.2 determinism milestone.
- `live-entity-enum` — `entityIds/entities/componentsOf`; `query([])` works today. Land with the schema-reflection inspector push.
- `template-create-flow` — `create-domecs` CLI is a new publishable package (release-infra, not engine API). Doc-only workspace checklist could be pulled forward.
- `test-consolidator-disable-via-handle` — `CONSOLIDATE_FAULTS_NAME` is documented as disable-able but there's **no public by-name `SystemHandle` lookup** on `World` → the escape hatch may be unreachable. Needs an API decision first.
- `test-event-handler-throw-behavior` — `events.ts:83-89` `flush()` has no try/catch (a throwing `on()` handler escapes `step()`); `errors.ts:29 event_handler_threw` is defined but never constructed. Quarantine vs delete-dead-variant is a product decision.
- v0.2+ roadmap: range index, worker host, async/chunked snapshot, spatial layers, virtualized views, multi-world `EntityRef`, scene schema registry, benchmarks.
