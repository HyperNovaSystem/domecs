## DOMECS v3.0.0

All seven `@domecs/*` packages at 3.0.0. A major release: it fixes what rebuilding Harbor Authority (exemplar #2) found wrong or missing in the engine ([`doc/FINDINGS_harbor.md`](../FINDINGS_harbor.md), H-1 to H-18 and P-1 to P-4), and several of those fixes change behaviour. `^2.0.0` ranges do not pick up 3.0.0; the sibling packages peer on `^3.0.0` of `@domecs/core`.

### Highlights

- **Fixed steps are exact.** `step(fixedStep)` runs exactly one fixed step, and `step(n × fixedStep)` exactly n, at any step size, however long the world has run. 2.x counted steps as `floor(total / step)` over a float total, which lost a step from tick 22,785 of `step(1/60)` (H-16).
- **Fixed systems see their step's clock.** Inside a `fixed` system `ctx.time.scaledDelta` is the step (times the divisor for a `rateHz` system), `elapsed` is the fixed clock and `fixedTick` the step's index, so integrating with `scaledDelta` covers the same ground at any time scale. `world.time` gains `fixedTick` and `alpha` for interpolation (H-3). Sub-rate systems take a `phase` to spread them over their period (H-14).
- **Events inside the fixed schedule.** An event system with `fixed: true` runs in the fixed loop, and each step delivers what was emitted since the previous one: an emit in step k is handled in step k + 1 at 1× and at 64×. A fixed-step simulation can use events between its own systems and stay frame-rate independent (H-17). Event rules take `fixed: true` too.
- **Commands answer.** `defineCommand(name, { schema, description, handle })` makes a command whose handler returns `refuse(reason)` or `accept()`; `world.register(Cmd)` installs it, and `world.action()` / `bridge.act()` return that verdict — no resolver, no `Rejected` event. A `fixed: true` command is handled in the next fixed step. `describe()` marks commands, and act logs record verdicts, so replay reports a diverging refusal at the act (H-5, P-1).
- **Schemas say what a command needs.** `required`, `integer`, `min`/`max` (now enforced), `kind: 'entity'` with `with: ['Crane']` (alive, holding those components), and no `NaN` — all checked before any tick (H-6).
- **Panels, nesting, routing, order.** `@domecs/dom` views redraw on resources (`changedOn.resources`); `definePanel` renders markup derived from the world into its own slot with `paint`, an in-place DOM patch that keeps focus and the button being pressed (with `watchPresses`); `ViewDef.parent` nests one view's elements in another's; mounted elements carry `data-entity`, read back by `entityOf` and `MountHandle.on`; `ViewDef.order` keeps a list sorted (H-7–H-10).
- **Saves.** `@domecs/persist` saves take a codec (`jsonCodec`, now `canonicalJson`; `columnarCodec`, about a third of the text on a large world; or your own), can be read by `peek()` without decoding the save (a json save stays a plain JSON snapshot, with `meta` and `version` first), and carry the app's `appVersion` for `LoadOptions.accept` to refuse an old format before decoding (H-11, H-12, P-2).
- **Also:** a key tapped inside one frame keeps its press, and `preventDefaultKeys` leaves browser shortcuts and focused controls alone (H-1, H-2); rules take `rateHz` / `phase` (H-13); `world.signals.restored` after every restore (H-15); `runBranch` can skip its whole-world hash and proves each probe once (H-18); snapshots carry only the change marks a reader can still report (H-4); `defineComponent.of<T>()` states the name once (P-3); `world.setProfiling(true)` times every system, the inspector ranks them, and the renderer counts its work (P-4).

### Behaviour changes

- **A fixed system's `ctx.time` is its step's.** `delta` and `scaledDelta` are the step (× divisor), `elapsed` is `fixedTick × fixedStep`. Code that read the frame's values in a fixed system gets the step's now; code that used `ctx.time.fixedStep` is unaffected. A fixed rule's `dt` and `time` come from the same clock.
- **Snapshots are v4.** They carry `fixedTick`, `fixedAccumulator` and always `fixedStep`, and no longer `fixedBacklog`. v3 and older snapshots restore as before; `@domecs/persist` migrates 3 → 4; 2.x engines refuse v4. Every snapshot's default and strict hash changes (the envelope gained fields), so re-record golden hashes and act-log checkpoints. On the engine's own golden fixtures the state is unchanged.
- **Snapshots carry fewer change marks.** Marks on transient components are left out, and a mark is kept only while a system that watches that kind and component has not seen it. Two worlds that differ only in presentation tags are now strict-hash equal; strict hashes recorded by 2.x can differ.
- **The fixed step count can differ from 2.x** for a non-binary `fixedStep` after many ticks, where 2.x ran no step on some tick and two on a later one.
- **`world.action()` is stricter.** Non-finite numbers in a schema's `number` fields are refused, and `min`/`max` are enforced. `step` stays a widget hint.
- **`@domecs/persist`.** `save()` returns `ok({ codec, length })`; a json save is still a plain JSON snapshot, with `meta` and `version` as its first keys (other codecs write a header line first); the default codec writes `canonicalJson` values, which keeps `-0` and refuses `NaN` and cycles instead of writing `null`. Bare-JSON saves from 2.x still load.
- **`runBranch`.** `BranchRun.finalHash` is `string | null` (`null` with `finalHash: false`), and probes are proven read-only once per branch by default (`checkProbes: true` keeps the 2.x check at every call).
- **`@domecs/input`.** A tap shorter than a frame shows both edges. `preventDefaultKeys: true` no longer prevents keys with Ctrl/Meta/Alt held or on interactive controls, and prevents key repeats.
- **`@domecs/dom`.** Mounted elements carry `data-entity="<id>"` (`mountDOM({ stamp: false })` to opt out).

### Type-level changes

- `TimeState` gains `fixedTick` and `alpha`; `FixedSystemDef` gains `phase`; `EventSystemDef` gains `fixed`; `WorldSignals` gains `restored` and `resourceChanged`; `World` gains `setProfiling`; the manifest's systems gain `fixed` and `timing`, `WorldManifest` gains `timing`, `EventDescriptor` gains `command`.
- `FieldKind` gains `'entity'` — a `switch` over it needs a case; `FieldSchema` gains `required`, `integer` and `with`. `validateEventPayload` takes an options argument.
- `WorldSnapshot` gains `fixedTick`, `fixedAccumulator` and `pendingFixedEvents`; `ActRecord` gains `verdict`; `ReplayError` gains `verdict_mismatch`; `ActionResolver`'s context gains `verdict`; `BranchRun.finalHash` widens to `string | null`; `RunBranchOptions` gains `finalHash` and `checkProbes`.
- `@domecs/persist`: `save()` returns `Result<SaveReport, DomecsError>`; `LoadOptions` is `DecodeOptions`; `Divergence` keys widen; `ComponentFieldData` gains `required`, `integer`, `with`.
- `@domecs/dom`: `ChangedOn` gains `resources`; `ViewDef` gains `order` and `parent`; `MountOptions` gains `panels` and `stamp`; `MountHandle` gains `elementOf`, `on` and `stats`; `MountError` gains `invalid_parent` and `invalid_panel`.
- `@domecs/rules`: `RuleDef` gains `rateHz`, `phase` and `fixed`; `RuleDefPath` widens.
- `@domecs/input`: `preventDefaultKeys` widens to `boolean | string[] | (e) => boolean`; `InputPluginOptions` gains `interactiveSelector`.

### New APIs

- `@domecs/core`: `defineCommand`, `accept`, `refuse`, `isCommandType`, `eventSchema`, `defineComponent.of`, `defineResource.of`, `world.setProfiling`, `signals.restored`, `signals.resourceChanged`; types `CommandType`, `CommandDef`, `CommandContext`, `CommandVerdict`, `PayloadCheckOptions`, `PayloadWorld`, `SystemTiming`, `FrameTiming`.
- `@domecs/dom`: `definePanel`, `paint`, `watchPresses`, `entityOf`, `ENTITY_ATTRIBUTE`; types `PanelDef`, `ViewParent`, `ViewStats`, `PanelStats`.
- `@domecs/persist`: `peek`, `prepareSave`, `encodeSave`, `decodeSave`, `jsonCodec`, `columnarCodec`; types `SnapshotCodec`, `SaveHeader`, `SaveReport`, `DecodeOptions`.
- `@domecs/input`: `INTERACTIVE_SELECTOR`.
- `@domecs/inspector`: `createInspector({ profile: true })`, `bundle.timings()`; type `SystemTimingRow`.
