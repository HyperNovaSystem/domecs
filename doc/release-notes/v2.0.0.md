## DOMECS v2.0.0

All seven `@domecs/*` packages at 2.0.0. Two are new on npm:

- `@domecs/scene`: a `Parent` component, hierarchy queries, `despawnTree`, and parent-before-child transform composition
- `@domecs/rules`: a small, safe expression language and a rule interpreter that turns JSON rule data into world systems

This release carries every fix from the 2026-10-13 engine review and the 2026-07-17 review tranche. It is a major release because several of those fixes change behavior an app could rely on; see **Upgrading from 1.0.0**.

### Highlights

- Agent surface: `createAgentBridge` (reset / observe / act / step / snapshot), `world.action()` payload validation against declared schemas, and event-system triggers listed in `describe()`
- Snapshots carry the clock, the entity-id cursor and unseen change marks, so a restored world continues the live timeline; `restore()` validates before it touches world state
- Change filters report every mark since a system last ran, not just this tick's
- DOM: a change-gated commit costs what changed (50k entities, one change: 10.6 → 0.03 ms); a throwing view callback no longer jams the renderer; several `mountDOM`s per world
- `@domecs/persist`: `loadIfPresent`, `createLocalStorageStorage`, and component-type schema I/O
- Rules run about 4× faster than the first in-repo version and report errors as entity faults

### Upgrading from 1.0.0

- Upgrade the packages together. The other packages now peer-depend on `@domecs/core` `^2.0.0`, so install `@domecs/core` yourself.
- Several fixes change behavior an app could rely on: query iteration is ascending entity id; component `defaults` are copied per entity; rule errors are reported instead of swallowed; a DOM view with `update` but no redraw trigger is a mount error; `restore()` rejects a snapshot newer than the engine. Each is marked **behavior change** in the [CHANGELOG](https://github.com/HyperNovaSystem/domecs/blob/main/CHANGELOG.md).

Install:

```bash
npm install @domecs/core @domecs/dom @domecs/input
# optional
npm install @domecs/persist @domecs/inspector @domecs/scene @domecs/rules
```
