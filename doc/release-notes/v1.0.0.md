## DOMECS v1.0.0 — API-stable

First release of all five `@domecs/*` packages on npm:

- `@domecs/core`
- `@domecs/dom`
- `@domecs/input`
- `@domecs/persist`
- `@domecs/inspector`

### Highlights

- Deterministic ECS kernel with headless `step` / `stepOnce` / `stepN`
- Typed `world.action()` command boundary
- Retained multi-view DOM renderer
- Result-typed snapshot save/load + migrations
- Schema reflection via `world.describe()`

Semver is honored going forward; the product contract continues to harden via corrective 1.0.x releases. See [CHANGELOG](https://github.com/HyperNovaSystem/domecs/blob/main/CHANGELOG.md) and [plan/PLAN.md](https://github.com/HyperNovaSystem/domecs/blob/main/plan/PLAN.md).

Install:

```bash
npm install @domecs/core @domecs/dom @domecs/input
```
